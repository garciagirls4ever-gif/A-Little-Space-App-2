# A Little Space

Complete upload package:
- index.html
- styles.css
- app.js
- manifest.webmanifest

Upload all four files to the root of the GitHub Pages repository.

IMPORTANT:
The account screen in this front-end is a local prototype. It is NOT sufficient for protecting sensitive information online. Before public launch, connect authentication and the journal/memory data to a real secure backend such as Supabase or Firebase with per-user database security rules. Never put passwords, private keys, or service-role keys in this repository.
